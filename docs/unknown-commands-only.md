# Comandos desconhecidos ativos

Não há comandos desconhecidos ativos nesta etapa.

Os nomes que constavam na lista anterior foram retirados do Soul-List por decisão do proprietário, pois não deveriam ser adicionados ao bot. Os comandos `jail` e `track` deixaram de ser pendências: `jail` foi implementado como sistema de prisão medieval do RPG e `track` foi implementado como consulta ficcional de status dentro do RPG, sem rastreamento real, GPS, presença ou localização de pessoas.

Os menus adultos e comandos sensíveis permanecem excluídos do catálogo público.
